# Contributing to Bitgov

Bitgov is in its founding documentation phase. We welcome:

- **Corrections**: Factual errors, inconsistencies
- **Clarifications**: Confusing sections
- **Technical review**: Architecture and implementation feasibility
- **Cultural sensitivity review**: Ensuring inclusivity

## How to Contribute

1. **Open an issue** describing the problem/suggestion
2. **Submit a pull request** with proposed changes
3. **Discuss in issues** before major structural changes

## Code of Conduct

Bitgov is built on respect for all life. We require:
- Constructive, respectful discourse
- Focus on planetary wellbeing over individual ego
- Transparency in motivations and conflicts of interest

Violations will result in removal from the project.
